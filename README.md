# telefonun-yuzde-birle-yasamasi-enerji-piyasasi-duzenleme-kurumu
Telefonun yüzde 1 pille sonsuza kadar yaşamasını resmi enerji arz güvenliği olayı sayan, şarj aletini santral, kırmızı ikonu kriz masası, 'biraz daha gider' cümlesini milli seferberlik ilan eden Kurum. Gerçekten çalışır. Yüzde birler artık megavattır.
